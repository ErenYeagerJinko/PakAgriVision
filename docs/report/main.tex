\begin{abstract}
PakAgriVision is an AI-driven agricultural decision-support tool addressing late crop disease detection for Pakistani smallholder farmers. Building upon Deliverable~1's curated dataset foundations ($\sim$32,000 balanced images across 38 classes and 38-class treatment knowledge base), this Deliverable~2 report presents the complete Phase~3 Model Architecture and Phase~4 Training and Evaluation pipeline. We implement a deep residual classifier (ResNet-50) featuring a custom regularization head ($p=0.30$ dropout and 38-class projection) and an explicit Grad-CAM explainability target layer. Training incorporates class-weighted cross-entropy with label smoothing, AdamW optimization, a two-stage progressive fine-tuning schedule (head-only warm-up followed by cosine annealing), and a structured 13-trial hyperparameter tuning protocol. The resulting baseline model achieves \textbf{99.64\% validation accuracy} and a \textbf{0.9961 macro-F1 score} with a validation loss of \textbf{0.0169}. We detail evaluation methodology across macro precision/recall, one-vs-rest AUC-ROC, top-3 metrics, error analysis, a comprehensive Bias Check auditing class-size disparities and lab-vs-field generalization gaps, and the complete individual contribution breakdown.
\end{abstract}
