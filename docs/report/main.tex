\begin{abstract}
PakAgriVision is an experimental agricultural decision-support application for leaf-image disease identification and sourced treatment guidance. This report consolidates dataset preparation, model development, evaluation and local application deployment across Deliverables~1--3. The curated PlantVillage dataset contains 31,694 images across 38 classes, linked to a schema-validated treatment knowledge base. A fine-tuned ResNet-50 uses a dropout classification head, class-weighted cross-entropy, AdamW optimization and a head-warm-up/cosine schedule; a 13-trial tuning protocol examines alternative configurations. The baseline achieves \textbf{99.64\% validation accuracy} and \textbf{99.71\% lab test accuracy}, but only \textbf{24.73\% field test accuracy}, demonstrating a substantial generalization gap. A local Flask dashboard integrates image upload, top-three predictions, real Grad-CAM overlays and confidence-aware chemical, organic and cultural-management panels. Below 60\% confidence, product instructions are withheld and users are directed to obtain an in-person assessment. Strict checkpoint and knowledge-base checks prevent fabricated fallback diagnoses. Source links, product-label precautions and agronomist consultation remain necessary even at higher confidence; neither confidence nor visual attention establishes a verified disease diagnosis.
\end{abstract}
