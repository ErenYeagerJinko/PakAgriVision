\section{Dataset Acquisition \& Provenance}
\label{sec:dataset}

\subsection{PlantVillage Benchmark Dataset}
The primary baseline training dataset is the public PlantVillage benchmark~\cite{plantvillage}, obtained via the Kaggle API (\texttt{abdallahalidev/plantvillage-dataset}).
\begin{itemize}
    \item \textbf{Initial Benchmark Scale:} 54,303 raw color images across 14 distinct crop species and 38 distinct crop-disease pairings.
    \item \textbf{Quality Curation \& Balance:} Following file integrity verification and perceptual deduplication (Section~\ref{sec:cleaning}), classes were capped at a maximum of 1,000 clean, unique samples to mitigate extreme class imbalance (e.g., Orange Huanglongbing previously having 5,507 samples vs. Potato healthy having 152), yielding a balanced curated baseline of \textbf{31,694 verified clean images}.
    \item \textbf{Input Resolution:} Standardized $256\times256$ pixels in RGB color format (1:1 square aspect ratio).
    \item \textbf{License \& Integrity:} CC0 Public Domain / Open Educational License.
\end{itemize}

\subsection{Real-World Field Dataset}
\label{sec:field}
PlantVillage images were captured under controlled lighting against plain backgrounds, so accuracy on its own test split overstates how a model will perform on leaves photographed in the field. To measure this gap, we assembled a separate field set of 150 images with real backgrounds (soil, other foliage, hands, sky).

\paragraph{Source and licence.}
All 150 images come from the PlantDoc dataset~\cite{plantdoc} (\url{https://github.com/pratikkayal/PlantDoc-Dataset}), released under CC-BY-4.0. Each image is recorded in \texttt{field\_meta/field\_labels.csv} with its filename, PlantVillage label, source, URL, licence and the original PlantDoc folder. The images themselves are not committed to Git; a zip of \texttt{data/raw/field/} is shared via the Google Drive link in \texttt{data/README.md}.

\paragraph{Selection rules.}
We kept only images showing a clearly visible leaf on a real field background, and skipped blurry, watermarked or lab-style images. We aimed for five images per class. Three classes have more (Tomato early blight and Potato late blight 10, Tomato late blight 8) because they were used to make up the 150-image target, and Tomato spider mites has only 2 because PlantDoc contains only two usable images for it.

\paragraph{Class mapping.}
PlantDoc uses its own folder names (e.g.\ \textit{Soyabean leaf}, \textit{Bell\_pepper leaf spot}), so every PlantDoc class was mapped to the exact PlantVillage class string in \texttt{field\_meta/class\_mapping.csv}. The field set covers 28 of the 38 PlantVillage classes. The remaining 10 have no PlantDoc counterpart and are excluded from the lab-vs-field comparison: \texttt{Apple\_\_\_Black\_rot}, \texttt{Cherry\_\_\_Powdery\_mildew}, \texttt{Corn\_\_\_healthy}, \texttt{Grape\_\_\_Esca\_Black\_Measles}, \texttt{Grape\_\_\_Leaf\_blight Isariopsis\_Leaf\_Spot}, \texttt{Orange\_\_\_Haunglongbing(Citrus\_greening)}, \texttt{Peach\_\_\_Bacterial\_spot}, \texttt{Potato\_\_\_healthy}, \texttt{Strawberry\_\_\_Leaf\_scorch} and \texttt{Tomato\_\_\_Target\_Spot}.

\paragraph{Test/adapt split.}
\texttt{data\_scripts/make\_field\_splits.py} splits each class separately with seed 42: about one third of the images (rounded, with at least one image in each split whenever a class has two or more) go to \texttt{splits/field\_adapt.csv} and the rest to \texttt{splits/field\_test.csv}. Because most classes have five images, this gives 3 test and 2 adapt images per class, so the overall split is 92/58 (61\%/39\%) rather than exactly two thirds. Table~\ref{tab:field_counts} lists the counts, generated by the script into \texttt{splits/field\_split\_stats.csv}.

\textbf{Rule:} \texttt{field\_test.csv} is never used for training, tuning or threshold selection. Only \texttt{field\_adapt.csv} may be used, and only for the fine-tuning mitigation in a later phase.

\paragraph{Limitations.}
\begin{itemize}
    \item All images come from a single source (PlantDoc); none are our own photographs from Pakistani fields, so the set measures the general lab-to-field gap rather than local conditions.
    \item With 2--10 images per class, per-class field accuracy will be noisy; results should be reported mainly in aggregate. Tomato spider mites (2 images) gives a single test image.
    \item Some mappings are approximate: PlantDoc's \textit{Bell\_pepper leaf spot} is treated as \texttt{Pepper\_\_\_bell\_Bacterial\_spot}, \textit{Corn leaf blight} as \texttt{Corn\_\_\_Northern\_Leaf\_Blight}, and \textit{Apple rust leaf} as \texttt{Apple\_\_\_Cedar\_apple\_rust}.
    \item A second team member must double-check every label before the split is final; any removed images will be dropped from \texttt{field\_labels.csv} and the split script re-run.
\end{itemize}
